# Cosmetic & Aesthetic Agents: The "10 Micro-Demos" Strategy

This plan focuses exclusively on the **Cosmetic / Aesthetic Medicine** niche (Clinics, MedSpas, Dermatologists).
**Goal**: Allow the user (Clinic Owner) to run these 10 scenarios in < 5 minutes on their own device to feel the power.

## The Concept: "Try Your Agent"

After scraping their site, the user lands on a "Playground". They can click "Test Scenario" buttons or just Type.

---

### 1. The "Zero-Effort" Appointment (Core) 📅

- **Trigger**: User types: "Quiero botox para las arrugas de la frente."
- **Bot Action**: "Perfecto. Para frente solemos usar 1 vial. Precio 350€. ¿Te va bien jueves tarde?"
- **Dashboard PAYOFF**:
  - Visual: 🗓️ **Calendar Slot Fills** (Animation).
  - Data: "Service: Botox Full Face. Value: 350€."

### 2. The "Upsell" Master (Revenue) 💸

- **Trigger**: User types: "Quiero cita para limpieza facial."
- **Bot Action**: "Genial. Veo que tienes piel mixta. Muchas clientas añaden **Vitamina C** por solo 20€ más para dar brillo. ¿Te lo apunto?"
- **User**: "Venga vale."
- **Dashboard PAYOFF**:
  - Visual: 📈 **Ticket Size Increased**.
  - Data: "Upsell Converted: +20€. Total: 70€."

### 3. The "Ghost" Hunter (No-Show Prevention) 👻

- **User**: "Síp."

## Technical Requirement: "Preset Buttons"

For the demo to be "Simulatable by them", the Chat Interface needs **"Preset Scenario Buttons"** above the input bar:
[ 📅 Book Botox ] [ 💸 Too Expensive ] [ 👻 Ghost Risk ] [ 📸 IG Photo ]
Clicking inputs the prompt instantly.
